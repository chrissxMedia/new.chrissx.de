We plan to update the Unifont font on `fonts.chrissx.de` from 14.0.03 to 18.0.01. Most characters are unchanged, and none are removed, so we expect little impact. The old font files will remain available. [Check the PR for more details](https://github.com/chrissxMedia/fonts.chrissx.de/pull/3).
