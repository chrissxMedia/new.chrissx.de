We updated the Unifont font on `fonts.chrissx.de` from 14.0.03 to 18.0.01 on 2026-10-02. Most characters were unchanged, and none were removed, so we expected little impact. We kept the old font files available. [Check the PR for more details](https://github.com/chrissxMedia/fonts.chrissx.de/pull/3).
